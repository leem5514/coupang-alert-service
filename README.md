# 살까말까 — 쿠팡 가격 알림

쿠팡 상품 키워드와 목표가를 등록하면 주기적으로 최저가를 확인하고, 목표가에 도달했을 때 이메일을 보내는 개인용 프로젝트입니다.

## 실행

```bash
npm install
npm run install:browsers
copy .env.example .env
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다. 기존 터미널 UI는 `npm run dev:cli`로 실행할 수 있습니다.

`.env`에는 쿠팡 파트너스 API 키와 Gmail 앱 비밀번호를 설정합니다. API 키가 없으면 설정에 따라 Playwright 스크래퍼를 보조 수단으로 사용합니다.

## 현재 MVP 범위

- 키워드·목표가·알림 이메일 등록
- 활성 알림 목록과 현재 최저가 확인
- 다음 확인 시각과 API 잔여 호출 수 표시
- 가격 이력 저장 및 알림 삭제
- 목표가 도달 시 이메일 알림

> 쿠팡 페이지 구조 변경이나 봇 차단으로 스크래퍼가 실패할 수 있습니다. 실제 서비스로 확장할 때는 공식 API 사용을 우선하고 호출량·약관을 다시 확인하세요.
